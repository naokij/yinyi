# 字体目录

此目录用于存放打印模板使用的中文字体文件。

## 推荐字体

### 1. 霞鹜文楷（推荐）
- 开源、免费商用
- 温馨文艺，适合拍立得风格
- 下载地址：https://github.com/lxgw/LxgwWenKai

放置文件：
- LXGWWenKai-Regular.ttf
- LXGWWenKai-Bold.ttf

### 2. 系统字体（备选）
程序会自动尝试使用系统自带字体：
- macOS: 苹方 (PingFang)
- Linux: 文泉驿正黑 (WenQuanYi Zen Hei)

## 安装方法

```bash
cd fonts
wget https://github.com/lxgw/LxgwWenKai/releases/download/v1.510/LXGWWenKai-Regular.ttf
wget https://github.com/lxgw/LxgwWenKai/releases/download/v1.510/LXGWWenKai-Bold.ttf
```

如果没有安装自定义字体，程序会使用系统默认字体。
